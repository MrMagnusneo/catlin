# Kotlin / Jetpack Compose — модуль 2

Воспроизводимый учебный Android-проект по практическим заданиям 1–9.

## Запуск
1. Установите Android Studio с Android SDK 35 и JDK 17.
2. Откройте корень репозитория как проект Android Studio.
3. В репозитории пока нет бинарного `gradle-wrapper.jar`, поэтому для первоначальной настройки нужен установленный локально Gradle 8.11.1. В корне проекта выполните `gradle wrapper --gradle-version 8.11.1`, затем `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).\n4. Дождитесь синхронизации Gradle в Android Studio (при первом запуске требуется интернет).
5. Запустите конфигурацию **app** на эмуляторе Android API 26+.
6. На главном экране выберите нужное задание (1–8); задание 9 — автоматические UI-тесты.

## Соответствие заданиям
1. `Hello(name: String?)` — отображение имени или сообщения при `null`.
2. Три `@Preview`: Portrait, Landscape, Round. Посмотрите вкладку Preview в `MainActivity.kt`.
3. Три способа стилизации текстового ресурса (`Text`, `maxLines`, `Ellipsis`).
4. Широкая кнопка с рамкой, скруглением и тенью.
5. Контейнер с кругом и инициалами.
6. Векторный drawable с кругом, размещение и окрашивание.
7. Примеры вертикальной `Column` и горизонтальной `Row` компоновки.
8. Трекер воды: +250 мл, завершение дня, количество успешных дней подряд.
9. `WaterTrackerTest.kt` — три UI-теста Compose.

Запуск инструментальных тестов: правой кнопкой по `app/src/androidTest/java/.../WaterTrackerTest.kt` → **Run 'WaterTrackerTest'**, с подключённым эмулятором. Или `./gradlew connectedDebugAndroidTest` при наличии Gradle wrapper.

**Важно:** ранее подготовленные для отчёта изображения — демонстрационные иллюстрации ожидаемого интерфейса. Они не являются снимками реально запущенного этого проекта и не доказывают прохождение тестов. Фактические скриншоты следует снять после запуска кода. При этом экран приложения здесь намеренно упрощён для воспроизводимости и может отличаться от этих иллюстраций.
