# Практические задания по Kotlin — модуль 2

Репозиторий с заданиями по дисциплине «Проектирование и разработка мобильных приложений на языке Kotlin».

Во втором модуле рассматриваются основы создания интерфейсов Android-приложений с использованием **Jetpack Compose**: компоненты `Text`, `Button`, `Image`, контейнеры `Column`, `Row`, `Box`, модификаторы, состояние интерфейса и UI-тестирование.

## Содержание

| № | Задание |
|---|---|
| 1 | Функция приветствия с nullable-параметром |
| 2 | Предпросмотр для вертикального, горизонтального и круглого экранов |
| 3 | Оформление текста и строковые ресурсы |
| 4 | Стилизация кнопки |
| 5 | Контейнер с кругом и инициалами |
| 6 | Векторный ресурс и размещение изображения |
| 7 | Компоновка элементов с помощью Column и Row |
| 8 | Счётчик потребления воды |
| 9 | UI-тесты счётчика потребления воды |
| 10 | Корзина товаров: расчёт суммы и корректная рекомпозиция |

## Структура проекта

- `app/src/main/java/com/mrmagnusneo/catlin/MainActivity.kt` — интерфейсы заданий 1–8 и меню заданий.
- `app/src/main/java/com/mrmagnusneo/catlin/ShoppingCart.kt` — корзина товаров (задание 10).
- `app/src/main/res/` — строковые и графические ресурсы.
- `app/src/androidTest/java/com/mrmagnusneo/catlin/WaterTrackerTest.kt` — UI-тесты задания 9.

## Запуск

1. Открыть проект в **Android Studio**.
2. Проверить установку **JDK 17** и **Android SDK 35**.
3. Выполнить синхронизацию Gradle.
4. Запустить конфигурацию `app` на эмуляторе или Android-устройстве (API 26 и выше).
5. На главном экране выбрать задание из списка.

В репозитории пока не добавлены файлы Gradle Wrapper. При необходимости его можно создать из командной строки при установленном Gradle 8.11.1:

```bash
gradle wrapper --gradle-version 8.11.1
```

Для просмотра задания 2 следует открыть функции с аннотациями `@Preview` в файле `MainActivity.kt` и использовать режим **Design / Preview** в Android Studio.

## Тестирование

Тесты расположены в `WaterTrackerTest.kt`. Для запуска необходимо подключённое устройство или работающий эмулятор. В Android Studio можно выбрать **Run 'WaterTrackerTest'** из контекстного меню файла.

Проверяются увеличение количества воды на 250 мл, сброс значения при завершении дня и увеличение числа последовательных дней при достижении 1500 мл.
